# Engineering Calculator

A command-line Python tool for common mechanical engineering calculations, built with AI assistance as a first-year B.Tech Mechanical Engineering student at VIT-AP.

## Features
- Unit converter (mm ↔ inches, kg → Newtons)
- Stress calculator (force ÷ area, result in MPa)
- Circle area calculator

## How to run
1. Install Python 3
2. Download main.py
3. Run: python main.py

- Writing functions and menus in Python
- Using AI tools to build and debug code
- Applying basic mechanics formulas in code
